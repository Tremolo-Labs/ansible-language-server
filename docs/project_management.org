**** TODO Fix Context Detection for Incomplete Plays
:PROPERTIES:
:ID:       b4c7d892-8e5f-4c9a-ad2f-9f6e3b4c8d0e
:END:

**Problem:**
=test_play_context_completions= fails because =_analyze_yaml_context= returns =UNKNOWN=
when the cursor is in an incomplete play that lacks identifying keys.

**Test case:**
#+begin_src yaml
---
- name: Test play
  |  # cursor here (line 2, char 2)
#+end_src

**Root cause analysis:**
=_analyze_yaml_context= in =services.org= identifies contexts using key-based heuristics:
- PLAY: requires =hosts= key present
- BLOCK: requires =block= key present
- TASK: requires parent =tasks=/=pre_tasks=/=post_tasks= key

When a play only has =name:= (no =hosts:= yet), none of these conditions match,
so it returns =UNKNOWN=.

**Path analysis:**
#+begin_example
  0: stream
  1: document
  2: block_node
  3: block_sequence      <- TOP-LEVEL SEQUENCE (plays list)
  4: block_sequence_item
  5: block_node
  6: block_mapping       <- Current mapping with keys={'name'}
#+end_example

**Proposed fix:**
In =_analyze_yaml_context=, before returning =UNKNOWN=, add a fallback check:

1. Check if we're in a top-level sequence (block_sequence whose parent chain is
   =block_node -> document=)
2. If so, and we're inside a =block_mapping=, assume =PLAY= context

This is safe because:
- Playbooks are defined as lists of plays at the document level
- Any mapping inside a top-level sequence item is a play definition
- Tasks are always nested under =tasks:=/=handlers:= keys (already handled)

**Implementation location:**
- File: =docs/implementation/services.org=
- Function: =_analyze_yaml_context= (line ~1175)
- Add before =return AnsibleContext.UNKNOWN=

**Code sketch:**
#+begin_src python
# Fallback: check if we're in a top-level sequence (play list)
for i, node in enumerate(path):
    if node.type == "block_sequence":
        # Check if parent is block_node and grandparent is document
        if i >= 2 and path[i-1].type == "block_node" and path[i-2].type == "document":
            # We're in a top-level sequence - assume PLAY context
            return AnsibleContext.PLAY

return AnsibleContext.UNKNOWN
#+end_src
